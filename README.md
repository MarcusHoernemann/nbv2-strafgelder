# NBV Strafkasse

Die **NBV Strafkasse** ist eine maßgeschneiderte Progressive Web App (PWA) zur digitalen Erfassung und Verwaltung der Strafkasse an unseren Spieltagen. Diese Anwendung ist **ausschließlich für die vereinsinterne Nutzung im NBV konzipiert** und nicht für externe Nutzer oder andere Vereine geeignet.

## Features

* **100% Offline-fähig:** Die App funktioniert komplett ohne aktive Internetverbindung. Alle Eingaben während des Spieltags werden lokal auf dem Gerät verarbeitet.
* **Plattformunabhängig (PWA):** Kann als native App-Erfahrung direkt über den Browser auf Android- und iOS-Geräten installiert werden.
* **PDF-Export:** Nach Abschluss eines Spieltags lässt sich auf Knopfdruck eine übersichtliche PDF-Zusammenfassung generieren und herunterladen.
* **Vereinsbindung:** Fest integrierte, vereinsspezifische Regeln, Beträge und Vorgaben, die exklusiv auf den NBV zugeschnitten sind.

## Installation auf dem Smartphone

Da es sich um eine PWA handelt, muss die App nicht über einen App Store heruntergeladen werden. Der Aufruf erfolgt über die interne URL des Vereins.

**Für Android-Nutzer (Google Chrome):**
1. Die URL der Strafkassen-App im Chrome-Browser öffnen.
2. Im Menü (drei Punkte oben rechts) auf **"Zum Startbildschirm hinzufügen"** (oder "App installieren") tippen.
3. Die App ist nun als Icon auf dem Homescreen verfügbar und kann offline gestartet werden.

**Für iOS-Nutzer (Apple Safari):**
1. Die URL der Strafkassen-App im Safari-Browser öffnen.
2. Unten in der Mitte auf das **Teilen-Symbol** (Viereck mit Pfeil nach oben) tippen.
3. Nach unten scrollen und **"Zum Home-Bildschirm"** auswählen.
4. Die App befindet sich nun auf dem Homescreen und arbeitet offline.

## Wichtige Hinweise zur Nutzung

* **Datenverlust bei Cache-Leerung:** Da die App vollständig offline arbeitet, werden laufende Spieltagsdaten im lokalen Speicher (Local Storage) des Browsers abgelegt. Das manuelle Löschen der Browser-Daten löscht auch ungespeicherte Eingaben.
* **PDF-Sicherung:** Es wird dringend empfohlen, den PDF-Download unmittelbar nach dem Ende des Spieltags durchzuführen, um die finalen Daten dauerhaft und sicher zu dokumentieren.
